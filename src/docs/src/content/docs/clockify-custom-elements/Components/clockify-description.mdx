## Features

The `<clockify-description>` component allows you to:

- Display the description field of a time entry.
- Get recent time entry suggestions on focus.
- Get filtered time entry suggestions by typing.

## Installation

To use the `clockify-description` component, you need to first make sure you import the base styles and components, as described in the [Getting started](../..#installation) section.

Then, if you need to import only this component, you can add this to any HTML document:

```html
<script type="module" src="https://resources.developer.clockify.me/validation-widget/latest/clockify-description.js"></script>
```

or import it directly into your module:

```javascript
import "https://resources.developer.clockify.me/validation-widget/latest/clockify-description.js";
```

## Events

| Event    | Description                                                                                       |
|----------|---------------------------------------------------------------------------------------------------|
| `change` | Emitted when the description status changes. Contains the updated `description` in the `detail` property. |
| `select` | Emitted when the user selects a suggested time entry. Contains the time entry object in the `timeEntry` property of the `detail` property. |
| `error`   | Emitted on global error, with `error` in the `detail` property.                                       |
| `success` | Emitted on global create/update/delete actions, with `message` and `data` in the `detail` property.                                       |

## Styling

This component uses `@shoelace-style/shoelace` components and can be styled using CSS custom properties and parts.

You can change properties of the topmost container `<clockify-description>`, like you would do for any HTML element, like so:

```css
clockify-description {
  width: 50px;
}
```

## Parts
For styling elements inside the Shadow DOM, you can use the `part` attribute if exposed.

Parts exposed by the `clockify-description` component:

| Part                  | Description                                                                      |
|-----------------------|----------------------------------------------------------------------------------|
| `input`               | Capture the input                                                                |
| `suggestions`         | Capture the `ul` element where the suggested time entries are appended           |
| `suggestion`          | Capture each `li` of the list of suggested time entries                          |

You can then style these parts like this:

```css
clockify-description::part(suggestion) {
  background-color: #fefefe;
}
```
