## Features

The `<clockify-billable>` component allows you to:

- Display and toggle the billable status of a time entry.
- Choose between a button or a switch interface using the `switch` property.
- Automatically synchronize changes with Clockify backend or emit events for custom handling.
- Supports read-only and disabled states.

## Installation

To use the `clockify-billable` component, you need to first make sure you import the base styles, as described in the [Getting started](../..#installation) section.

Then, if you need to import only this component, you can add this to any HTML document:

```html
<script type="module" src="https://resources.developer.clockify.me/validation-widget/latest/clockify-billable.js"></script>
```

or import it directly into your module:

```javascript
import "https://resources.developer.clockify.me/validation-widget/latest/clockify-billable.js";
```

## Usage

<Aside>This component needs an authentication token to work. Make sure to follow the instructions on the [Authentication](/index#authentication) section of the Getting started page. If you provide a token named `token` via `localStorage` or a parameter named `auth_token` in the query parameters, you can view it below. This is true for all examples on this page.</Aside>

### Basic usage (Button)

Add the `clockify-billable` component to your HTML:

<Tabs>
    <TabItem label="Rendered" active>
        <div style="width: 50px;">
            <clockify-billable></clockify-billable>
        </div>
    </TabItem>
    <TabItem label="Code">
        <Code code={`<clockify-billable></clockify-billable>`} lang="html" />
    </TabItem>
</Tabs>

### Using as a Switch

To display the billable component as a switch, set the `switch` property to `true`:

<Tabs>
    <TabItem label="Rendered">
        <div style="width: 100px;">
            <clockify-billable switch></clockify-billable>
        </div>
    </TabItem>
    <TabItem label="Code">
        <Code code={`<clockify-billable switch></clockify-billable>`} lang="html" />
    </TabItem>
</Tabs>

## Properties

| Property         | Type                                        | Description                                                                                                                                      | Default             |
|------------------|---------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|---------------------|
| `disabled`       | `Boolean`                                   | Disables component interactions.                                                                                                                 | `false`             |
| `addon`          | `Boolean`                                   | Enables add-on features.                                                                                                                         | `false`             |
| `readonly`       | `Boolean`                                   | Makes component read-only.                                                                                                                       | `false`             |
| `billable`       | `Boolean`                                   | Sets the initial billable status.                                                                                                                | `false`             |
| `switch`         | `Boolean`                                   | Determines if the component is displayed as a switch. If `false`, displays as a button.                                                          | `false`             |
| `workspaceId`    | `String`                                    | Workspace ID for API calls.                                                                                                                      | `""`                |
| `timeentryid`    | `String`                                    | ID of the Clockify time entry.                                                                                                                   | `""`                |
| `token`          | `String`                                    | Authentication token.                                                                                                                            | `""`                |
| `tokenkey`       | `String`                                    | The localStorage key in which the authentication token is stored                                                                                 | `""`                |
| `tokensearchparam`| `String`                                   | The URL search parameter key on which the authentication token is passed                                                                         | `""`                |
| `homeurl`        | `String`                                    | Base URL for Clockify API calls.                                                                                                                 | `""`                |
| `homeurlkey`     | `String`                                    | Key for retrieving the base URL from storage.                                                                                                    | `""`                |
| `endpoint`       | `String`                                    | Custom API endpoint.                                                                                                                             | `""`                |
| `syncPickedData` | `'EMIT_EVENT_ONLY'` \| `'SYNC_ON_CHANGE'`   | Specifies sync behavior (`'EMIT_EVENT_ONLY'` or `'SYNC_ON_CHANGE'`). If you choose `'SYNC_ON_CHANGE'`, you need to provide the `timeentryid` property. | `'EMIT_EVENT_ONLY'` |

## Events

| Event    | Description                                                                                       |
|----------|---------------------------------------------------------------------------------------------------|
| `change` | Emitted when the billable status changes. Contains the updated `billable` status in the `detail` property. |
| `error`   | Emitted on global error, with `error` in the `detail` property.                                       |
| `success` | Emitted on global create/update/delete actions, with `message` and `data` in the `detail` property.                                       |

## Styling

This component uses `@shoelace-style/shoelace` components and can be styled using CSS custom properties and parts.

You can change properties of the topmost container `<clockify-billable>`, like you would do for any HTML element, like so:

```css
clockify-billable {
  width: 50px;
}
```

For styling elements inside the Shadow DOM, you can use the `part` attribute if exposed.

## Notes

- **Data Synchronization**: The component allows sync behaviors like `'EMIT_EVENT_ONLY'` for minimal data emission.
- **Accessibility**: The component uses accessible HTML elements and can be navigated using keyboard controls.
