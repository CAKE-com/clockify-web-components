## Features

This component aims to mimic the functionality, look and feel of the project picker used in the Clockify web application.

It:
- Can fetch Projects, Clients and Tasks, categorizing them in this hierarchy: Clients > Projects > Tasks, with two special Project categories: Favorites and No client
- Can create Projects, Clients and Tasks
- Can mark/unmark a Project/Task as favourite
- Can search for Projects, Clients and Tasks
- Can use the Task filter, where you can quickly find a task by using the task@project syntax
- Can display Projects/Tasks in isolation, under a single client, by clicking on the rightmost icon besides the Client name
- Can display custom names for Project, Client and Task. These settings can be customized under the *Organize time by* section under Workspace settings
- Emits a `change` event on Project/Task selection
- Accepts `projectId`, `clientId` and `taskId` properties, if you need to control the selection from the outside
- Can update a time entry or multiple time entries, if you pass the `timeentryid` or `timeentryids` properties respectively (Note: multiple time entry ids are not yet implemented. Also, if you're using this component within an add-on, it won't work due to Clockify not being enabled for add-ons. Both are soon to be available.)

## Installation

To use the clockify-project-picker component, you need to first make sure you import the base styles, as described
in the [Getting started](../..#installation) section.

Then, if you need to import only this component, you can add this to any html document:

```javascript
<script type="module" src="https://resources.developer.clockify.me/validation-widget/latest/clockify-project-picker.js"></script>
```

or import it directly into your module

```javascript
import "https://resources.developer.clockify.me/validation-widget/latest/clockify-project-picker.js";
```

## Usage

<Aside>This component needs an authentication token to work. Make sure to follow the instructions on the [Authentication](../..#authentication) section of the Getting started page. If you provide a token named `token` via `localStorage` or a parameter named `auth_token` in the query parameters, you can view it below. This is true for all examples of this page.</Aside>

### Basic

Add the `clockify-project-picker` component to your HTML:

<Tabs>
    <TabItem label="Code" active>
        <Code code={`<clockify-project-picker></clockify-project-picker>`} lang="html" />
    </TabItem>
    <TabItem label="Rendered">
        <div style="width: 200px;">
            <clockify-project-picker></clockify-project-picker>
        </div>
    </TabItem>

</Tabs>

### In an add-on

Add the `clockify-project-picker` component to your HTML, with the `addon` property set to `true` to use it inside an add-on. This will send the authentication token on the `X-Addon-Token` header.

<Tabs>
    <TabItem label="Code" active>
        <Code code={`<clockify-project-picker addon></clockify-project-picker>`} lang="html" />
    </TabItem>
    <TabItem label="Rendered">
        <div style="width: 200px;">
            <clockify-project-picker addon={true}></clockify-project-picker>
        </div>
    </TabItem>
</Tabs>

## Events

| Event     | Description                                                                                         |
|-----------|-----------------------------------------------------------------------------------------------------|
| `change`  | Emitted when a project, client, or task is selected. Contains `selectedProject`, `selectedClient`, and `selectedTask` in the `detail` property. |
| `error`   | Emitted on global error, with `error` in the `detail` property.                                       |
| `success` | Emitted on global create/update/delete actions, with `message` and `data` in the `detail` property.                                       |

## Styling

This component uses `@shoelace-style/shoelace` and a set of classes aiming to mimic the Clockify style of components. It has light and dark themes enabled by default.

You can change properties of the topmost container `<clockify-project-picker>`, like you would do for any html element, like so:

<Code lang="css" code={`clockify-project-picker{
    width: 100%;
}`} />

However, you cannot directly access elements inside the Shadow DOM directly using CSS. In a custom element, such elements are exposed via the `part` property, and accessed using taht same keyword, like so:

<Code lang="css" code={`clockify-project-picker::part(header){
    color: #333;
}`} />

## Parts
Parts exposed by the `clockify-project-picker` component:

| Part                  | Description                                                                      |
|-----------------------|----------------------------------------------------------------------------------|
| `header`              | Capture the header, that renders the selected Project/Task                       |
| `overlay`             | Capture the overlay, that contains the list of Clients/Projects/Tasks            |


## Notes

- **Data Synchronization**: The component allows sync behaviors like `EMIT_EVENT_ONLY` for minimal data emission.
- **Accessibility**: The dropdown can be navigated with keyboard controls and has custom tooltips for project details.
