# Clockify generic elements

Clockify generic elements are a set of web components that can be used to build custom Clockify integrations. They are built using the [Web Components](https://developer.mozilla.org/en-US/docs/Web/Web_Components) standard and can be used in any web application.
Visit the documentation for more information on how to use them.
