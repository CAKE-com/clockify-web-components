## Overview

Clockify Web Components use a system of CSS Design Tokens (also known as [CSS Custom Properties](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_cascading_variables/Using_CSS_custom_properties)) to allow for easy customization of their visual appearance. These tokens control various aspects like colors, spacing, and typography. By overriding these tokens in your own CSS, you can tailor the components to match your application's theme without needing to modify the component internals.

## How to Use Design Tokens

Design tokens are essentially CSS variables that you can redefine. Our components will then pick up your custom values.

### Identifying Tokens

Each component exposes a set of tokens relevant to its styling. Use your browser's developer tools to inspect components and see which tokens are available. Look for CSS custom properties (e.g., `--clockify-primary`).

### Overriding Tokens

To customize a component, you can override its design tokens in your own stylesheet. Make sure your stylesheet is loaded *after* the component's styles.

**Examples**

  ```css
  /* Your custom-styles.css */
  :root { /* Or a more specific selector if needed */
    --clockify-primary: #4A90E2; /* Your desired blue */
    --clockify-text: #FFFFFF; /* White text */
    --clockify-primary-600: #357ABD; /* Darker blue on hover */
  }

  /* If you only want to target a specific instance of a button */
  .my-custom-themed-button {
    --clockify-primary: #50C878; /* Emerald green */
    --clockify-text: #FFFFFF;
    --clockify-primary-600: #3AA05A;
  }
  ```

Then, apply this class to your component:
```html
  <clockify-button class="my-custom-themed-button">Custom Button</clockify-button>
```
